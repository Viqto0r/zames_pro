{% comment %} The theme gallery: its own page (docs/themes.md and docs/themes-ru.md), included only where the page sets `theme_gallery: true`. Why an include and not a hand-written grid: 29 screenshots repeated in EN and RU would drift the moment a theme is added. The data is docs/_data/themes.yml, so Jekyll loops over it and the pages stay readable. Why plain links and not a JS carousel: the screenshot IS the feature here (29 palettes ship with the agent), so the grid must work with JS off - every tile is a real link to the full-size PNG. site.js only collapses the grid behind the toggle below and upgrades a left click into a dialog lightbox. Each tile paints its OWN palette background (bg) before the PNG loads, and a light theme gets .is-light so its caption flips to dark text: without that a gallery of 29 images first flashes dark rectangles and then the five light palettes arrive as white holes. {% endcomment %}
