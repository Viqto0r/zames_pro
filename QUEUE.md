**Баг:** финальный ОТЧЁТ часто пересказывает уже сделанные шаги теми же
будущими формами, которые ищет эвристика: «Tests pass. Now I will run the
build.», «I have updated the README. Now let me commit.», «Все тесты проходят,
now let me run lint.». Эвристика срабатывала, луп до 3 раз переспрашивал

на ПОЛНОМ ответе. Проверено запуском: все три фразы давали `true`.

**Фикс:** перед проверкой будущих форм добавлено распознавание
ЗАВЕРШЁННОГО шага (present perfect/past и русские глаголы прошедшего
времени): «passed/updated/fixed/…», «have/has …», «проходят», «исправил»,
«добавил» и т.п. Чистое обещание действия («Let me run the tests», «Проверю
тесты») по-прежнему ловится. Списки слов сверяются через `includes` (не
одной склеенной регуляркой — V8 с кириллической альтернативой внутри
группы с `\b` молча не находил совпадение; это отдельная ловушка, из-за
которой первые варианты фикса «не срабатывали»).
