### Такт 5 (2026-10-17) — исправлено

**Цель:** web/SSRF + `WebFetch` (чистая часть `htmlToText`).

**Баг:** `htmlToText()` (src/web.ts) раскодировал числовые HTML-сущности через
голый `String.fromCodePoint(...)`, который БРОСАЕТ `RangeError` на значении
вне Unicode (`&#999999999;`), на суррогате (`&#xD800;`) и на NaN. Исключение
вылетало из `htmlToText` в catch обработчика `WebFetch` — и вся страница
возвращалась как `Error fetching <url>: Invalid code point 999999999`.
Агент терял документ целиком из-за одного битого символа. Второй дефект:
пара суррогатов, записанная двумя ссылками (`&#55357;&#56832;`, т.е. эмодзи),
декодировалась по половинам и оставляла в тексте два lone surrogate.

**Фикс:** `decodeEntityCode()` — недопустимая ссылка отбрасывается (не бросает),
а пара «high + следующий low» склеивается в один астральный символ; состояние
сбрасывается на входе в `htmlToText`, чтобы не утекало между документами.

**Тест:** `test/web-html.test.ts` +3 кейса (вне диапазона, суррогат/пустая
ссылка, склейка пары) — RED до фикса (`RangeError`, «lone high surrogate»),
GREEN после.

**Гейты:** `npm test` 1093 теста (1083 pass, 0 fail, 10 skip), `typecheck`,
`lint`, `format:check`, `build` — зелёные.

**Коммит:** `39a9c0b`.

### Такт 11 (2026-10-17) — исправлено

**Цель:** web/SSRF — `isPrivateIp` / `assertPublicUrl` в `src/web.ts`.

**Баги (два обхода SSRF-защиты `WebFetch`):**
1. `isPrivateIp` понимал только канонический dotted-quad IPv4. WHATWG URL и
   `inet_aton` принимают и неканонические литералы (`2130706433`, `0x7f.1`,
   `0177.0.0.1`, `127.1`) — все резолвятся в `127.0.0.1`, и страж их пропускал.
2. URL API оставляет КВАДРАТНЫЕ СКОБКИ у IPv6-литерала, а `net.isIP('[::1]')`
   возвращает 0 — адрес уходил в DNS-ветку и никогда не проверялся как адрес:
   `http://[::ffff:127.0.0.1]/` проходил.

**Фикс:** `parseLegacyIpv4()` нормализует легаси-литерал (1–4 части,
десятичные/восьмеричные/hex) в uint32 перед проверкой диапазонов; скобки у
IPv6-хоста снимаются до `isIP`/`isPrivateIp`.

**Тесты:** `test/web.test.ts` +1 (неканонические литералы, RED),
`test/ssrf-redirect.test.ts` +1 (bracketed IPv6 loopback блокируется, публичный
IPv6 пропускается, RED). Живая проверка через `assertPublicUrl` — перечисленные
URL теперь блокируются.

**Гейты:** `npm test` 1103 теста (1093 pass, 0 fail, 10 skip), `typecheck`,
`lint`, `format:check`, `build` — зелёные.

**Коммит:** `7c03ec6`.
